## Descripción del proyecto
Este proyecto consiste en desarrollar y organizar diferentes actividades y videojuegos utilizando Python y la biblioteca Pygame. Durante su elaboración se realizaron distintos ejercicios prácticos para conocer cómo funciona la programación de videojuegos y aplicar los conocimientos adquiridos en clase.

## Objetivo general
Aplicar los conocimientos de programación mediante la creación de videojuegos sencillos con Pygame, utilizando elementos como funciones, ciclos, eventos, estructuras de datos y detección de colisiones.

## ¿Qué es Pygame y para qué se utiliza?
Pygame es una biblioteca de Python que permite desarrollar videojuegos y aplicaciones multimedia. Ofrece herramientas para crear ventanas, mostrar imágenes, reproducir sonidos, controlar personajes mediante el teclado y detectar colisiones entre objetos.

Se utiliza principalmente para aprender programación de videojuegos y desarrollar proyectos interactivos de una manera práctica.

## Relación de Pygame con los temas vistos en clase
Al trabajar con Pygame se pueden aplicar diferentes conceptos de programación:

- **Variables:** permiten almacenar puntos, velocidades y posiciones.
- **Condicionales:** ayudan a tomar decisiones dentro del juego.
- **Ciclos:** mantienen el videojuego funcionando y actualizando la pantalla.
- **Funciones:** permiten organizar el código en diferentes tareas.
- **Eventos:** detectan las acciones del usuario, como presionar una tecla o cerrar la ventana.
- **Estructuras de datos:** permiten almacenar información y organizar elementos del juego.
- **Colisiones:** permiten detectar cuando dos objetos entran en contacto.

## ¿Qué significa que Pygame permite utilizar mucho o poco de su biblioteca?
Esto significa que Pygame es una biblioteca flexible, ya que podemos utilizar únicamente las herramientas que necesitamos para nuestro proyecto. Por ejemplo, si solamente queremos crear una ventana y mover un personaje, no es necesario utilizar todas las funciones disponibles.

De esta manera podemos comenzar con programas sencillos e ir incorporando nuevas características conforme adquirimos más conocimientos.
